# Company Profile SR12

Website company profile modern untuk promosi dan pengenalan produk SR12 berbasis HTML, CSS, dan JavaScript.  
Dibuat dengan desain elegan, responsive, dan terintegrasi langsung dengan WhatsApp untuk mempermudah konsultasi serta pemesanan produk oleh customer.

---

## ✨ Tentang Project

Project ini dibuat sebagai media digital company profile untuk membantu promosi usaha produk SR12 agar lebih profesional, modern, dan mudah diakses secara online oleh masyarakat.

Website menampilkan berbagai kategori produk seperti skincare, bodycare, haircare, herbal, serta fitur interaktif yang memudahkan pelanggan dalam berkonsultasi maupun melakukan pemesanan.
